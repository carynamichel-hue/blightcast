# BlightCast

Boxwood blight risk planner — accumulated infection risk (USPest.org / Oregon
State University model v3.0) on the weather at your town, with your own alert
level, spray log, station data and season outlook.

**Use it here: https://carynamichel-hue.github.io/blightcast/**

This repository holds the built site. There is no server and no account —
your data stays in your browser (see the 🔒 Privacy statement in ⚙ Setup).

Built with Nuxt at Overdevest Nurseries.
